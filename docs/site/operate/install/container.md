# Install with containers

This is one of three peer shapes (see [Install](index.md)). The Compose stack runs `port49d`,
`port49-broker` and a three-member etcd with client-certificate auth. It is also the quickest way to
try port49. Read the four requirements on the index page first, then follow the guide below, which is
the deployment's own README.
