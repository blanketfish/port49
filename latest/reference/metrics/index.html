    Metrics¶

    Every metric port49d and port49-broker export on /metrics, with its type, labels and help text. The list is read from the registered collectors. Each section holds the series whose names share a second word, such as accounting in port49_accounting_spool_depth. No metric carries a device's identity as a label. The last column links each shipped alert whose expression uses the series.

    accounting¶

    Metric Type Labels Meaning Alerts
    port49_accounting_attributions_total counter attribution Accounting records accepted, by attribution. port49_accounting_foreign
    port49_accounting_spool_depth gauge Accounting records waiting for the sink.
    port49_accounting_spool_drops_total counter stage Accounting records discarded by the spool, by the stage that discarded them. port49_accounting_spool_drops
    port49_accounting_spool_quarantines_total counter Unreadable spool files renamed aside for an operator.
    port49_accounting_spool_sync_seconds histogram Seconds one accounting spool group commit spent in fsync and close (plus the directory fsync of a new file); every record in the batch waits on it. port49_accounting_spool_disk_slow

    Metric Type Labels Meaning Alerts
    port49_admin_touch_total counter outcome Admin-level calls by proof outcome (required, proved, refused, unavailable); alert on a run of refused: someone with a certificate or bearer is trying an admin call without the token. port49_admin_touch_refused

    port49_broker_connection_events_total counter event Broker connections refused at accept or closed by the broker, by event.

    port49_broker_idempotency_refusals_total counter outcome Mint requests refused whole at their Idempotency-Key, by outcome.
    port49_broker_item_errors_total counter error Mint items the broker could not decide, by API error code.
    port49_broker_logouts_queue_full_total counter Logouts from another region that found this runner's queue full; each one owes a pass over the whole logout set, which follows.
    port49_broker_mint_gate_closed gauge 1 while this broker waits to mark the bundle last judged in doubt for a swap, minting nothing under the swapped bundle, and from its start until it has seen a takeover done for the bundle it serves; 1 for longer than a minute is a store that does not answer, or refuses, the mark, or no runner that judges this broker's bundle. port49_broker_mint_gate_closed
    port49_broker_tls_handshake_failures_total counter reason TLS handshakes the broker's listener did not complete, by reason.

    port49_directory_lookups_total counter outcome Directory resolutions by outcome: fresh, grace, unavailable, unmapped, ambiguous, collision. port49_directory_lookups_ambiguous
    port49_directory_password_configured gauge 1 when this broker has a directory_password verifier; alert on port49_directory_enrollment_store_ok being 0 or absent where this is 1. port49_directory_enrollment_store_lost
    port49_directory_pins_reseal_last_complete_timestamp_seconds gauge The Unix time the last complete re-seal pass of the directory pins ended; absent before one.
    port49_directory_pins_sealed_previous gauge Directory pins the last complete re-seal pass left sealed under encryption.previous; remove encryption.previous only at 0, read on the keyspace holder from a pass that ended after the last restart of the rotation's step 2. Absent until a pass completes, and where the store holds no pins.
    port49_directory_pins_unopenable gauge Directory pins the last complete re-seal pass could not open under either encryption key; their principals cannot bind, mint or refresh. Alert above 0 where port49_store_keyspace_held is 1. port49_directory_pins_unopenable
    port49_directory_prewarm_last_success_timestamp_seconds gauge The Unix time the last pre-warm pass finished; 0 before one has.
    port49_directory_prewarm_principals gauge People and workloads together that the last pre-warm pass verified and stored.
    port49_directory_queries_total counter server, outcome Directory queries by server (host:port) and outcome: ok, fault (the server's), error (the query's answer), refused (the server refused the dial or bind without a fault).
    port49_directory_refresh_last_complete_timestamp_seconds gauge The Unix time of the last scheduled refresh that verified every principal; 0 before one has, absent where no scheduled refresh runs. port49_directory_refresh_stale, port49_directory_refresh_half_ceiling
    port49_directory_selected gauge server 1 for the directory server queries are sent to (sticky selection).
    port49_directory_server_up gauge server 1 while the directory server's breaker is closed. port49_directory_server_down
    port49_directory_site_crossings_total counter Selections that crossed sites: consistency events, membership read at the other site may lag directory replication.
    port49_directory_walks_truncated_total counter Nested-group walks that ended at max_depth or the node bound with groups unconfirmed; those groups are not granted.

    port49_policy_fail_closed_compositions gauge Compositions answered fail-closed under the policy in force now: those users are denied all but the allows. port49 policy test names them. port49_policy_fail_closed_compositions

    port49_policy_refresh_pending gauge 1 from a policy swap or grant expiry until its settle pass has carried it into every live login context. port49_policy_refresh_pending
    port49_policy_reloads_total counter outcome Attempts to put a changed policy file in force, by outcome.

    process¶

    The standard Prometheus process collector adds the process_* series (CPU time, open file descriptors, memory, start time). process_start_time_seconds is read by port49_directory_refresh_stale and port49_directory_refresh_half_ceiling, which gate a refresh timestamp on uptime so that a fresh start does not fire them.
